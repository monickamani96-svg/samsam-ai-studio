# Samsam Ai Studio

وب‌سایت فارسی و راست‌چین برای معرفی آموزش‌ها و محتوای هوش مصنوعی.

## اجرا
فایل `index.html` را در مرورگر باز کنید. سایت بدون نصب وابستگی اجرا می‌شود.

## انتشار با GitHub Pages
1. فایل‌های پروژه را در شاخه `main` مخزن قرار دهید.
2. در GitHub وارد Settings → Pages شوید.
3. گزینه Deploy from a branch را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/ (root)` قرار دهید و Save کنید.

## نکته مدیریت محتوا
دکمه «مدیریت» امکان افزودن مطالب را در همان مرورگر با localStorage فراهم می‌کند. این نسخه هنوز پنل مدیریت ابری، ورود کاربران، بارگذاری دائمی فایل یا پایگاه داده ندارد.
